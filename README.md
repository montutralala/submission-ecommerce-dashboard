# submission-ecommerce-dashboard
Proyek ini adalah sebuah dashboard analitik interaktif yang dibangun menggunakan Python dan library Streamlit untuk memproses data dari Brazilian E-Commerce Public Dataset (Olist) periode 2016 hingga 2018. Aplikasi ini dirancang untuk menjawab berbagai pertanyaan bisnis strategis, mulai dari pemantauan tren pendapatan bulanan yang mencapai puncaknya pada November 2017, hingga analisis performa kategori produk di mana kategori health & beauty unggul dalam perolehan pendapatan. Selain visualisasi tren, dashboard ini juga mengimplementasikan segmentasi pelanggan berbasis metode RFM (Recency, Frequency, Monetary) untuk mengidentifikasi kelompok pelanggan yang paling berharga, seperti segmen Champions, serta memberikan peringatan terkait rendahnya tingkat retensi pelanggan di platform tersebut. Melalui antarmuka yang intuitif, pengguna dapat melakukan filter rentang waktu secara dinamis dan mengeksplorasi korelasi antara skor ulasan dengan volume penjualan di setiap kategori produk.
