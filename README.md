# submission-ecommerce-dashboard
Dashboard interaktif ini menganalisis data E-Commerce Brasil (Olist) 2016–2018 menggunakan Python dan Streamlit. Fiturnya mencakup pemantauan tren revenue bulanan, analisis performa kategori produk, dan segmentasi pelanggan berbasis RFM. Proyek ini membantu mengidentifikasi peluang bisnis serta strategi retensi pelanggan.
